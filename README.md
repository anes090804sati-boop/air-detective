# Air Detective V4.10 — 지역별 민원창구 자동 변경

이번 패치는 V4.9의 **3개 파일(`index.html`, `style.css`, `script.js`)**만 교체합니다.

## 기능

- 분석 전 세 번째 카드는 **서울시 응답소**로 유지합니다.
- 사용자가 피해 장소를 입력하고 **현장 분석 시작하기**로 민원 초안을 만들면, 그 피해 장소의 시·도에 맞게 **세 번째 카드의 이름 / 설명 / URL이 자동 변경**됩니다.
- 예: 서울 → **서울시 응답소**, 부산 → **부산민원120**, 경기도 → **경기도 민원 안내**, 대전 → **대전시 민원신청**.
- 지역에 실제 온라인 민원 접수 사이트가 확인된 경우 직링크를 제공하며, 나머지는 공식 지자체 누리집의 민원 안내로 연결합니다. 각 지자체가 모두 ‘응답소’라는 브랜드를 운영하는 것은 아닙니다.
- 지자체를 알아내지 못하면 다른 도시라고 임의로 추측하지 않고 **관할 지자체 확인 필요**라고 표시하고 국민신문고로 안내합니다.
- 한 곳만 추천 강조하는 기존 기능은 유지하고, 지도 / 경로 검색 / 분석 기능은 그대로 둡니다.

## 위치 확인의 기준

사용자 현재 위치가 아닌 **민원 발생 장소**를 우선 사용합니다. 시·도를 직접 입력하지 않았더라도 주소 검색(Nominatim)이 성공하면 반환되는 행정구역 정보를 이용합니다. 주소 검색이 실패하거나 행정구역을 확정할 수 없을 경우 관할 기관을 추측하지 않습니다.

## GitHub에 적용하기

1. 이 ZIP의 3개 코드 파일만 기존 GitHub 루트에 덮어쓰고 Commit changes 합니다.
2. `data/facilities.json`, `.github/workflows/`, `scripts/` 및 `vercel.json`은 절대 삭제하거나 교체하지 마세요.
3. Vercel의 최신 배포가 Ready면 분석 화면에서 피해 장소에 `부산광역시 해운대구`, `경기도 수원시`, `서울특별시 강남구` 등을 각각 넣고 생성 결과를 확인합니다.

※ 지역별 사이트는 사용자 민원을 자동으로 제출하지 않습니다. 공식 홈페이지의 신청 메뉴·인증 절차는 해당 기관에서 진행해야 합니다.
