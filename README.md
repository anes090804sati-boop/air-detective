# Air Detective V4.9 — 지도 보기 / 경로 검색하기

P-NET 01 · 갈색 + 초록색 테마 · 무료 정적 웹앱 · 기존 V4.8에 추가하는 패치입니다.

## 지금까지 반영한 요청 정리

- **문제 분석**: 먼지 피해 설명, 현장 사진(선택), 무료 브라우저 사진 분류, 주변 시설·기상자료를 활용한 참고 분석
- **분석 결과 4단계**: ① 현재 상황 추정 → ② 오염 가능 요인 → ③ 종합 분석 → ④ 대응 방법
- **민원**: 실제 행정기관에 제출할 수 있도록 쓰인 민원 초안, 복사/다운로드, 여러 공식 접수처 중 한 곳 강조
- **오염원 지도**: 대한민국 OpenStreetMap 시설 스냅샷으로 등록 공사장·산업시설 표시, 마커/클러스터, 내 위치 및 가까운 공사장 찾기
- **디자인**: 크림/베이지 + 갈색 + 세이지 그린
- **이번 V4.9 추가**: 오염원 지도 안에 **「지도 보기 / 경로 검색하기」** 두 번째 단계 메뉴

## V4.9의 새 기능

**지도 보기**는 기존 기능 그대로 유지합니다. 시설 검색, 유형별 필터, 내 위치, 가장 가까운 OSM 등록 공사장, 상세 팝업을 사용할 수 있습니다.

**경로 검색하기**는 아래처럼 사용합니다.

1. 오염원 지도 → **경로 검색하기** 선택
2. 출발지/도착지를 텍스트로 입력하거나, **지도에서 찍기**를 눌러 지도 클릭으로 지정
3. 출발지에는 **내 위치** 사용 가능 (브라우저 위치 권한 필요)
4. 기준선 양옆 **100 / 200 / 400 / 600m** 중 선택
5. **공사장 위치 확인하기** 클릭 → 해당 직선 주변의 OSM 등록 공사장을 **빨간 마커**로 표시
6. 빨간 마커나 목록을 누르면 이름·등록 상세정보·직선 기준 근접 거리가 나옵니다.

⚠ **경로 검색은 실제 도로 길찾기가 아닙니다.** 출발점과 도착점을 잇는 직선을 기준으로 탐색합니다. 실제 이동 경로와 소요 시간, 현재 공사 진행 여부, 현장의 먼지 측정값, 도로 통제는 알 수 없습니다. 별도 길찾기 API를 사용하지 않으며 시간대별 공사 일정도 제공하지 않습니다.

## 기존 Vercel 사이트에 업데이트하는 방법 (중요)

기존 GitHub `anes090804sati-boop/air-detective` 저장소의 **루트**에 이 ZIP 안의 다음 **3개 파일만 덮어써 주세요.**

- `index.html`
- `style.css`
- `script.js`

`README.md`는 선택적으로 업데이트할 수 있습니다.

**기존 `data/facilities.json`은 삭제·덮어쓰기하지 마세요.** 이 파일은 GitHub Actions가 이미 실제 전국 OSM 자료로 만들어 저장한 데이터입니다. 특히 예전 ZIP에 포함된 `{"status":"not_generated"}` 임시 파일로 교체하면 공사장 마커가 다시 사라집니다.

**기존 `.github/workflows/build-facilities.yml`, `scripts/`, `vercel.json` 등도 변경하지 마세요.** 이 ZIP에는 포함하지 않았습니다. 생성 작업을 다시 실행할 필요도 없습니다.

1. ZIP 압축 해제
2. GitHub 저장소 → Add file → Upload files
3. 위 3개 파일을 동일한 이름·위치로 교체 → Commit changes
4. Vercel Deployments에서 최신 배포가 **Ready**인지 확인
5. `https://air-detective.vercel.app/`에서 오염원 지도 → 두 내부 메뉴 확인

## 데이터 / 서비스 안내

- `data/facilities.json`: GitHub Actions에서 생성한 OpenStreetMap 공개 등록 시설 데이터. 새로운 지도 검색에서도 이 동일한 파일을 읽습니다.
- 주소 검색: Nominatim (공개 서비스 정책에 따른 제한 있음). 두 검색이 필요하면 순차 요청합니다. 안 되면 지도 클릭으로 지정할 수 있습니다.
- 위치 확인: 브라우저 Geolocation API. 권한을 허용한 경우에만 사용합니다.
- 지도: Leaflet + OpenStreetMap 타일/시설 데이터. 지도 타일 표시에는 인터넷이 필요합니다.
- OpenAI API 키, 네이버 지도 API 키, 추가 유료 API **불필요**.
